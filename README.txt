CLEAN OOO — SITE
=================

Abra o arquivo index.html em um navegador para visualizar o site.

Conteúdo incluído:
- Página responsiva para celular e computador
- Clean OOO / Oxi-sanitização / Ozônio / UV
- NXT19
- Serviços para veículos e ambientes
- Cadastro e agendamento (demonstração)
- Área de curiosidades
- As 2 imagens enviadas
- Os 2 vídeos enviados

IMPORTANTE:
O formulário atualmente é demonstrativo e não envia os dados para um servidor.
Para publicar e receber agendamentos, precisamos conectar o formulário ao WhatsApp,
e-mail, Google Forms ou a um backend.

Também deixei textos como "adicione seu número aqui" para você fornecer seus
dados reais e eu substituir.
